# SQL Practice Exercises

This repository includes several SQL exercises I completed during my training at Workearly.  
The challenges were done on the Coderbyte platform.

Each file is one exercise, and shows how I use basic and intermediate SQL.

## What I practiced

- SELECT, WHERE, and ORDER BY
- JOIN between two tables
- GROUP BY, COUNT, AVG
- Subqueries and NOT EXISTS
- Filtering with LIKE and IS NOT NULL
- LIMIT and sorting
- CTEs (WITH)

## File List

| File Name                                      | Description |
|-----------------------------------------------|-------------|
| `members_booked_all_facilities_over_10.sql`   | Members who booked all facilities with cost > $10 |
| `vendor_group_count_by_firstname.sql`         | Count vendors grouped by FirstName |
| `top_10_action_films_2005.sql`                | Top 10 rented Action films in 2005 |
| `count_names_with_e_and_long_lastname.sql`    | Rows with FirstName containing 'e' and long LastName |
| `average_bike_purchases_by_state.sql`         | Average bike purchases by state |
| `members_booked_all_facilities_subquery.sql`  | Members who booked all facilities (with subquery) |
| `customer_directory_sorted.sql`               | List of customers sorted by last and first name |
